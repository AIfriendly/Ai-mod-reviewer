# Music

Drop **royalty-free or properly-licensed** background tracks here (`.mp3`, `.wav`,
`.m4a`, `.ogg`). The pipeline picks one at random per video, loops it to length,
and ducks it under the narration.

⚠️ Do **not** use Skyrim's in-game music or copyrighted songs — they will trigger
YouTube Content ID claims. Safe sources:

- YouTube Audio Library (free, check the license per track)
- Creative Commons (honour the attribution / non-commercial flags — a
  "non-commercial" track on a monetized video still gets flagged)
- Licensed libraries (Epidemic Sound, Artlist, Uppbeat)

This folder is git-ignored except this README, so your audio files never get
committed.
